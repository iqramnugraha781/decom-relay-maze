Aturan Permainan DecomRelay Visual Peta

1. Dekomposisi Peta: Peta navigasi dipecah menjadi beberapa sub-modul (sesuai jumlah anggota kelompok). Jika tidak habis dibagi rata, sisa langkah masuk ke modul anggota terakhir.

2. Pratinjau Spasial: Perhatikan pergerakan karakter di peta saat kilas hafalan.

3. Pergerakan Real-Time: Tekan tombol panah (atau `WASD` / `Panah Keyboard`) untuk menggerakkan karakter ke petak selanjutnya secara langsung!

4. Penanganan Kesalahan: Jika salah langkah, karakter akan *teleport* kembali ke Checkpoint modul aktif, bukan ke Start awal.

5. Mode Rute: "Rute Sama" — kedua tim menghafal peta identik bersama. "Rute Berbeda" — tiap tim menghafal peta unik miliknya sendiri secara bergiliran.

6. Mode Endless: Setiap tim punya 3 nyawa. Tiap kesalahan mengurangi 1 nyawa. Setiap lap tuntas, rute makin panjang & kecepatan hafalan makin cepat. Tim kehabisan nyawa berhenti; game berakhir saat kedua tim habis nyawa atau guru menekan "Selesai".
